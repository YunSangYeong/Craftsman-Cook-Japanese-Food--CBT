전기기능사 기준 앱 `b9a682ccff1b460334b78d5bfad9375b7ec4fbb6`을 재사용한 비공식 학습 앱.
최신 main `76b990b8720adfa85c22a0a8f699b17094aa357b`의 CBT 표준 v1.4.0 폴더 전체를 복사하고 AGENTS.md에 연결했다. 기존 저장소는 README만 있었고 초기 Git 상태는 깨끗했다.

## 실행

Node >=22.12 (현재 24.22.1), `npm ci --cache /tmp/cbt-npm-cache`, `npm run dev`.
`npm test`, `npm run build`, `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e`.
설정 스크립트: docs/environment-setup.sh, 시작 지침: docs/start.md.
환경 설정 draft 저장 도구가 INVALID_ARGUMENT을 반환해 클라우드 설정 저장은 확인되지 않았다. 위 파일은 로컬 대안이며 draft 저장이나 게시를 대신하지 않는다.

https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=7912
2026-11-11 요청은 프록시 `curl: (56) CONNECT tunnel failed, response 403`으로 실패했다. 공식 페이지 내용을 읽지 못했고 출제기준 대조도 미완료다.
현재 학습용 설정: 통합 영역 ‘일식 재료관리, 음식조리 및 위생관리’, 객관식 4지선다 60문항/60분, 각 문항 동일 배점으로 100점 환산, 60점 이상 합격, 과락 없음, 미응답 오답.
이는 공식 검증 완료나 실제 시험의 영역별 분포 재현을 의미하지 않는다. 공식 기준과 실기 규칙은 별도로 확인해야 한다. 실기 시험은 구현 대상이 아니다.

## 문제은행: 실제 1,000개

|분류|수|
|---|---:|
|기출 원문|0|
|복원|0|
|자체 제작 개념형|60|
|자체 제작 계산 조건 변형|940|
|내부 검수 완료 합계|1,000|
|검증 대기/중복 등록|0|
|목표 대비 수량 부족|0|

통합 과목 1,000개. 개념형은 일식 조리 기초 39개와 위생·안전 21개.
계산은 배합 비례·가식부 수율·원가·질량 농도 4유형 각각 235조건이다. 독립 유형은 개념 60개와 계산 4개이며 1,000개 독립 개념이 아니다. 범위·난이도 편중이 있어 완전한 시험 대비 은행이라고 주장하지 않는다.
`python scripts/generate-bank.py`로 결정적으로 재생성한다. ID/본문+정렬된 보기 중복 검사를 수행하고 정답 위치를 순환한다.
계산 결과를 별도 TypeScript 역산 검사로 검증했다. 조건·공식·단위·대입은 해설에 기록한다. 개념형은 AI 일반 지식 기반 자체 작성 및 내부 문장/보기/정답 검토이며 외부 전문가 검수와 공식 출제기준 대조는 미완료다. 읽지 않은 교재를 출처로 인용하지 않는다. sourceUrl은 작성 저장소이며 외부 정답 증빙이 아니다. 연도·회차는 전부 null.
민간 문제를 복제하지 않았다. 코드 원저작권 MIT 고지 유지, 자체 문항 CC BY 4.0. 외부 기출 재배포 권한은 확보하지 않았으므로 기출을 싣지 않았다.

## 기능과 저장

대시보드, 실전·랜덤, 두 모드 Space 이동, 절대 종료시각·자동 제출, 답안 변경·즉시 저장, 결과·해설, 오답·북마크·통계, JSON/CSV 등록·중복 제거·검수 승인·내보내기·백업·초기화.
학습 기준 선택 메뉴와 상단 상시 면책 배너 없음. 독립 스크롤 메뉴 적용.
저장 namespace: Craftsman-Cook-Japanese-Food--CBT:v1. 최근 응답 5,000개·시험 30회 보관. 백업 다운로드 지원, 백업 복원 UI 없음. 손상 원본 보존 및 저장 오류 경고 유지. 브라우저/origin마다 기록이 다르며 iframe 저장 제한이 있을 수 있다.
시험은 검수 완료 은행에서 60개 추출. 계산 family별 우선 1개, 나머지 독립 문항 우선 선택 후 부족하면 같은 family의 다른 ID로 보충한다. 공식 출제 비율이 아니다.

## 검증 및 배포

실행 결과는 docs/validation.md에 기록한다. Chromium PC·Pixel 7 에뮬레이션이며 실제 휴대폰 검증은 미실행.
workflow는 main push → validate 성공 → Pages 배포, PR은 검증만 수행한다.
배포 사전 GitHub API 확인에서 `curl: (56) CONNECT tunnel failed, response 403`으로 최초 차단됐다. 정책에 따라 재시도·main push·수동 실행·대체 배포를 하지 않는다. 코드는 별도 브랜치에 보존한다. CI와 Pages는 이 작업에서 실행되지 않았고 공개 화면도 미확인이다.
예상 URL: https://YunSangYeong.github.io/Craftsman-Cook-Japanese-Food--CBT/ (배포 확인 URL이 아님).
